## Recent improvements

The C++ [bridge finder](cpp/bridges.cpp) uses iterative low-link DFS with edge identities to handle parallel edges and avoid recursion-depth limits; it reports normalized, sorted bridge pairs in O(V + E + B log B) time and O(V + E) auxiliary space (B is the number of bridges). Java [Dijkstra](java/Dijkstra.java) validates directed nonnegative-weight input, uses exact addition to detect unrepresentable paths without discarding representable alternatives, and returns -1 for unreachable vertices; its binary-heap bound is O(V + E log(E + 1)) time and O(V + E) auxiliary space.

The C++ binary search in [BS.cpp](BS.cpp) is safe on an empty vector and returns the first occurrence when a target is duplicated. The Java BFS in [BFSGraph.java](BFSGraph.java) uses `ArrayDeque` as its FIFO queue. The C++ merge-interval implementation sorts its by-value input and compacts merged intervals in that same vector before resizing, avoiding a separate result allocation while retaining closed-interval semantics and invalid-range validation. JavaScript Kahn traversal preallocates its FIFO worklist to the vertex count and advances a head index, avoiding front-removal shifts and queue resizing while preserving deterministic order and O(V + E) time. Python [Word Break](python/word_break.py) builds a trie and starts bounded trie walks only at reachable text-prefix positions, with expected O(D + nL) time and O(D + n) storage (D dictionary characters, n text length, L maximum word length). Root Java [BinarySearch.java](BinarySearch.java) uses half-open bounds and an overflow-safe midpoint to find the first matching index in O(log n) time and O(1) auxiliary space, including for empty arrays and duplicate values.

The C [circular queue](c/circular_queue.c) computes wrapped indices with bounded branch-based arithmetic rather than modulo, keeping enqueue and dequeue O(1) while avoiding division in those index updates. C++ [Bellman–Ford](cpp/bellman_ford.cpp) iterates the caller-owned edge list by const reference instead of copying it, reducing algorithm/output storage to O(V) (in addition to the caller's O(E) input list).

Python [longest palindromic substring](python/longest_palindromic_substring.py) now uses Manacher's algorithm for O(n) time and O(n) auxiliary space. Java [binary-tree diameter](java/BinaryTreeDiameter.java) now uses an iterative postorder traversal and explicit stack rather than recursion, retaining O(n) time and O(n) auxiliary space while remaining stack-safe for deeply skewed trees.

Java [Number of Islands](java/NumberOfIslands.java) reuses a growable primitive integer work stack instead of allocating a boxed queue for each component, retaining O(R*C) time and O(R*C) auxiliary memory without mutating the input. C++ [quickselect](cpp/quickselect.cpp) retains its `kthSmallest` API and uses an introselect-style depth budget with a sort fallback to bound worst-case time at O(n log n); average time is O(n), and worst-case auxiliary space is O(log n) for the sort fallback.

The C++ [merge-intervals](cpp/merge_intervals.cpp) checks now compare against a separate reference merge across exhaustive short input sequences, integer-boundary cases, and invalid ranges, while retaining in-place compaction. JavaScript [LRU cache](javascript/lru_cache.js) validates capacities as nonnegative safe integers, evicts before inserting, preserves `Map`'s SameValueZero handling of `-0`, and avoids relinking an already-most-recent node; deterministic differential stress tests cover the cache operations and list/map invariants.

C++ [Floyd–Warshall](cpp/floyd_warshall.cpp) validates edge endpoints before allocating its O(V²) distance matrix; deterministic randomized comparisons against a Bellman–Ford reference and additional disconnected-cycle and integer-boundary cases strengthen its checks. JavaScript [KMP search](javascript/kmp_search.js) directly scans one-code-unit patterns without allocating a prefix table, and its exhaustive short-input checks compare results with a naive UTF-16 reference.

Java [AVL tree](java/AvlTree.java) now supports O(log n) worst-case deletion, including successor replacement for two-child nodes and height/balance restoration after removal; assertion tests cover leaf, one-child, and two-child cases, absent keys, and all four deletion rotations. Python [coin change](python/coin_change.py) adds `minimum_coin_composition`, reconstructing a deterministic lexicographically smallest, nondecreasing optimal composition from the O(amount × number_of_coins) dynamic-programming table.

C++ [A* grid pathfinding](cpp/a_star_grid.cpp) stores distance and parent state in flat O(V) arrays rather than nested per-row structures, checks grid-cell-count multiplication before indexing, and reconstructs paths through flat indices; deterministic tie-breaking remains, with larger-grid endpoint, adjacency, and shortest-length checks. Python [longest increasing path in a matrix](python/longest_increasing_path_matrix.py) replaces recursive memoized DFS with reverse topological dynamic programming over larger-neighbor counts and a deque, preserving O(R × C) time and space while eliminating recursion-depth failure; a monotone path longer than Python's recursion limit is covered.

C++ [articulation points](cpp/articulation_points.cpp) uses iterative DFS frames for post-order low-link propagation, avoiding call-stack exhaustion on deep graphs; edge IDs distinguish a DFS parent edge from parallel back edges, and tests cover a 50,000-vertex chain alongside graph edge cases. Java [Word Ladder](java/WordLadder.java) now uses bidirectional BFS, expands the smaller frontier, and generates candidate neighbors by character substitution with dictionary lookups instead of scanning the whole dictionary for each visited word; exhaustive small-dictionary comparisons against an independent one-way BFS check correctness.

## Layout and conventions

The original demonstrations remain at the repository root; additions are grouped in directories by implementation language (`c/`, `cpp/`, `java/`, `javascript/`, `python/`, `rust/`, and `typescript/`). Dated index sections list new problems, while parallel implementations of an existing problem are listed separately under additional-language implementations. Solutions are standalone examples rather than a single linked application.

Complexity notes should state time and auxiliary-space bounds, identify relevant input sizes (for example, n items or V vertices and E edges), and name assumptions that affect the bound. Distinguish auxiliary space from input/output storage and do not imply a bound that the implementation does not meet.

## Tests

Run `scripts/test_all.sh` from any working directory to compile and run the repository's standalone demos and self-tests. Compiled artifacts go into a temporary directory that is removed on exit. C and C++ compilation uses strict warning flags; the runner defines `MAXIMUM_SUBARRAY_TESTING`, `LONGEST_UNIQUE_SUBSTRING_SELF_TEST`, `HASH_TABLE_SELF_TEST`, `MIN_HEAP_SELF_TEST`, `RABIN_KARP_TEST`, `BOYER_MOORE_HORSPOOL_TEST`, and `PRIME_SIEVE_TEST` for the guarded C tests and `BELLMAN_FORD_SELF_TEST` for the guarded C++ test entry point. Java checks enable assertions and use strict `javac` lint flags when `javac` is available, otherwise they use the Java source-file launcher. TypeScript is type-checked in strict mode; Rust sources are compiled with `rustc --edition=2021 --test -D warnings`. Missing toolchains are reported as skipped, while actual test failures cause a non-zero exit status. Toolchain availability may vary by machine.
